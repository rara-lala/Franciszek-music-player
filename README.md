# Bielawski · Salon Player

프란치셰크 카드 전용, 작고 움직일 수 있는 SillyTavern 음악 플레이어. v1.0.0

이것은 봇카드에 붙이는 HTML이 아니라 **SillyTavern의 브라우저 확장**입니다. 설치 후 카드 하나를 지정합니다. 지정한 카드의 일대일 채팅에서만 나타나며 다른 카드나 그룹 채팅으로 이동하면 음악이 정지합니다. 서버 플러그인, 별도 음악 API 키, 빌드 작업은 필요 없습니다.

먼저 SillyTavern을 실행하고 채팅 AI를 연결해 답변이 나오는 상태로 준비하세요. 이 ZIP은 SillyTavern 자체 설치 파일이 아닙니다. 처음 설치하는 경우 공식 안내는 https://docs.sillytavern.app/ 에 있습니다.

## 처음 설치하기 — GitHub 계정 없이

1. ZIP을 풀면 `bielawski-salon-player` 폴더가 나옵니다.
2. **SillyTavern이 실제로 설치된 컴퓨터/서버**에서 아래 위치에 그 폴더를 복사합니다.
   `SillyTavern/data/default-user/extensions/bielawski-salon-player/`
   여러 사용자 계정을 쓰면 `default-user` 대신 자신의 사용자 폴더를 사용합니다.
3. 결과가 `.../extensions/bielawski-salon-player/manifest.json`인지 확인합니다. 폴더가 두 번 중첩되면 안 됩니다.
4. SillyTavern을 새로고침합니다. 나타나지 않으면 SillyTavern을 재시작하고 확장 메뉴에서 활성화 상태를 확인합니다.
5. **프란치셰크 카드의 일대일 채팅을 엽니다.**
6. 확장 메뉴(퍼즐 아이콘)의 **Bielawski · 음악 플레이어 설정**을 누릅니다.
7. **지금 열린 카드를 프란치셰크로 지정**을 누릅니다.
8. 첨부곡이 첫 곡으로 준비됩니다. 소리가 안 나고 자동재생 차단 안내가 보이면 플레이어의 ▶를 한 번 누릅니다.

폰 브라우저로 PC의 SillyTavern에 접속한다면 폴더는 **PC에** 넣습니다. 폰 자체에서 Termux로 실행한다면 Termux 안의 SillyTavern 폴더에 넣습니다. 호스팅 서비스에서 파일 접근 권한이 없다면 아래 GitHub 설치 경로를 사용하세요.

## GitHub로 설치·관리하기 — 장기 사용에 권장

이 패키지는 그대로 GitHub 저장소에 올릴 수 있는 구조입니다. 아직 실제 GitHub 저장소를 생성하거나 공개하지 않았습니다.

1. GitHub에서 새 저장소를 만듭니다. 예: `bielawski-salon-player`.
2. 이 폴더의 **내용물**을 저장소 최상위에 올립니다. `manifest.json`, `index.js`, `style.css`, `core.mjs`, `settings.html`, `catalog.json`, `media/`, `fonts/`가 최상위에 있어야 합니다.
3. SillyTavern → 확장 → **Install extension / 확장 설치**에서 그 저장소의 HTTPS 주소를 입력합니다.
4. 설치 후 새로고침하고 위의 5–8번으로 카드를 연결합니다.
5. 나중에 수정한 파일을 GitHub에 올린 뒤 SillyTavern 확장 관리에서 업데이트합니다.

수동 설치 폴더에는 Git 정보가 없어 GitHub 업데이트가 작동하지 않습니다. GitHub 설치로 옮길 때는 기존 폴더를 별도 백업하고 제거한 다음 같은 이름으로 설치하여 중복 로딩을 피하세요. 사용자 설정은 SillyTavern의 확장 설정에 별도로 저장됩니다.

공개 저장소에는 누구나 소스와 포함 음원을 다운로드할 수 있습니다. 이 ZIP에는 채팅 기록·API 키·봇카드가 포함되어 있지 않습니다. 첨부 테마곡의 공개 배포 여부는 사용자에게 달려 있습니다. 공개하고 싶지 않으면 개인용 수동 설치로 쓰세요. 비공개 GitHub 저장소의 인증 방식은 설치 환경에 따라 달라질 수 있으므로 초보자용 기본 경로로 삼지 않았습니다.

## 조작

- `BIELAWSKI · SALON` 부분 드래그: 마우스/터치로 이동. 키보드로 초점을 맞춘 뒤 방향키로도 이동할 수 있습니다.
- `‹` / `›`: 허용된 곡 목록의 이전 / 다음. 끝에서는 처음으로 순환합니다.
- `▶` / `Ⅱ`: 재생 / 일시정지. 일시정지 상태를 AI가 임의로 해제하지 않습니다.
- `테마 ♧`: 첨부한 비엘라프스키 곡을 처음부터 재생합니다. 언제든 사용할 수 있습니다.
- `⚙`: 테마, 음량, 프롬프트, 곡 목록, 카드 연결을 바꿉니다.

기본 디자인은 크림·회녹색과 명조 계열 글꼴이며, 다크 모드는 짙은 회녹색입니다. 한국어·라틴 문자용 Noto Serif KR 기반 글꼴을 함께 넣어 외부 폰트 서버 없이 사용합니다. 글꼴을 불러오지 못하면 기기의 명조체로 대체됩니다. 음반 커버나 영상 화면은 없습니다.

## 자동 선곡은 어떻게 작동하나요?

이 확장은 ChatGPT 계정에 직접 연결되지 않습니다. **SillyTavern에서 현재 연결한 채팅 AI**의 `generateRaw`를 사용합니다.

1. 캐릭터의 답변이 표시되면 최소 간격(기본 1분)을 확인합니다.
2. 최근 8개 일반 메시지의 각 마지막 1,800자, 곡 목록, 사용자가 쓴 선곡 지침을 현재 AI에 보냅니다.
3. AI가 실제 목록의 곡 ID를 반환합니다. 없는 곡이나 임의 URL은 거부합니다.
4. 첫 테마곡 재생 중에는 곡을 자르지 않고 다음 곡으로 예약합니다. 다른 곡 재생 중에는 선곡 결과가 달라지면 전환합니다.
5. 곡이 끝나면 예약곡, AI 선곡 또는 허용된 순서의 다음 곡으로 이어집니다.

자동 선곡 호출은 **추가 토큰·요금**이 생길 수 있습니다. 최소 간격은 답변에 따른 요청에 적용되고, 곡이 끝나거나 ‘지금 선곡’을 누를 때는 별도로 요청합니다. 아무 대화도 없는데 일정 주기로 계속 AI를 호출하지 않습니다. 요청 결과는 채팅에 추가하지 않습니다. 대화 전송은 현재 설정한 AI 제공자에게만 이루어지고 이 확장 자체의 별도 서버는 없습니다.

AI 연결이 없거나 오류가 나면 현재 곡을 유지합니다. 기본 프롬프트 모드에서는 곡이 끝났을 때 허용 목록의 다음 곡으로 넘어갈 수 있습니다. 직접 작성 모드에서 조건에 맞는 곡을 판단하지 못하면 임의로 다른 곡을 틀지 않습니다.

## 두 가지 기본 프롬프트와 직접 수정

- **쇼팽곡만**: 쇼팽의 피아노 독주곡만 후보에 넣습니다.
- **낭만주의시대 피아노곡 전체**: 등록된 낭만주의 피아노 독주곡을 후보에 넣습니다.
- **직접 작성**: 글을 수정하면 자동으로 이 모드가 됩니다. AI가 전체 등록 목록에서 조건에 맞는 곡들을 정합니다. 다음·이전도 그 허용 목록 안에서 움직입니다. 먼저 ‘현재 장면으로 지금 선곡’을 눌러 목록을 정하세요.

‘전체’는 **선곡 가능한 작곡가·시대의 범위**이며 세상의 모든 녹음을 자동으로 검색하는 서비스는 아닙니다. 기본 목록은 위 5곡이고, 다른 곡을 들으려면 음원을 추가해야 합니다. 예를 들어 ‘리스트만’이라고 바꾸려면 리스트 음원이 있어야 합니다. 첨부 테마곡은 쇼팽 제한과 별개로 처음과 전용 버튼에서 재생하도록 의도한 예외입니다.

## 곡 추가하기 — JSON 편집 불필요

설정 → 곡 추가에서 작품명, 작품번호, 작곡가, 연주자, 시대, 편성, 분위기를 적고 음원 파일 또는 HTTPS 직접 음원 주소를 넣습니다.

- 파일은 브라우저 IndexedDB에 저장됩니다. 브라우저 데이터를 지우면 사라지고 다른 기기에 자동으로 옮겨지지 않습니다. 원본 파일을 따로 보관하세요.
- 메타데이터는 입력한 내용을 사용합니다. 추가 파일의 연주자·작품을 AI가 알아서 확인하지는 않습니다.
- URL은 오디오 자체의 주소여야 합니다. 로그인·DRM·유튜브/스트리밍 서비스의 페이지 링크는 재생하지 못합니다.
- 원격 URL은 해당 음악 서버에 접속합니다. 소장 파일은 로컬 브라우저에서 재생합니다.
- 기본 파일은 별도 삭제 UI로 지우지 않으며, 사용자 추가 곡만 삭제할 수 있습니다.

공유할 기본 곡을 추가하려는 개발자는 `catalog.json`에 기존 항목과 같은 형태로 추가하고 파일을 `media/`에 넣을 수 있습니다.

## 알아두면 좋은 점

- 소리 자동재생 허용 여부는 브라우저가 결정합니다. 허용되지 않으면 한 번 직접 ▶를 눌러야 합니다.
- 모바일 화면 잠금·절전 정책에 따라 백그라운드 재생이나 AI 요청이 중단될 수 있습니다.
- 선택 카드는 이름이 아니라 카드의 아바타 파일 식별자로 연결합니다. 카드를 삭제 후 재가져오기하여 파일 식별자가 바뀌면 다시 지정합니다.
- 그룹 채팅에는 나타나지 않습니다.
- 일반 HTML 게시글용 ‘JS 없이’ 디자인과 달리, 이 확장은 요청한 자동 선곡·드래그·재생 제어를 위해 JavaScript를 사용합니다.

## 개발·검증

빌드 없이 설치할 수 있습니다. `core.mjs`는 선곡 범위, 안전한 ID 검증, 카드 연결 판단, 위치 보정 로직입니다.

개발자용 테스트: `node --test tests/core.test.mjs`

`VALIDATION.md`에 검증 범위와 실제 SillyTavern 연결에서 남은 확인 항목을 정리했습니다. `preview-light.png`, `preview-dark.png`, `preview-settings.png`는 로컬 모의 환경에서 실행한 확장의 화면입니다.

공식 확장 문서: https://docs.sillytavern.app/for-contributors/writing-extensions/
