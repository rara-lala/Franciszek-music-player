# Franciszek music player 2.0.17
프란치셰크 카드에만 연결하는 SillyTavern 확장입니다. 첨부된 음악 4곡과 표지만 사용하며, YouTube 검색과 이전 외부 음원은 제거했습니다.

## 기존 버전에서 교체
1. SillyTavern을 종료합니다.
2. 기존 `SillyTavern/public/scripts/extensions/third-party/bielawski-salon-player` 폴더를 다른 곳에 백업한 뒤 제거합니다. 덮어쓰기만 하면 이전 음원이 남을 수 있습니다.
3. 이 압축파일의 `bielawski-salon-player` 폴더를 같은 위치에 넣습니다. `manifest.json`이 그 폴더 바로 안에 있어야 합니다.
4. SillyTavern을 다시 실행하고 브라우저를 새로고침합니다.
5. 프란치셰크 개인 채팅을 열고 확장 설정의 **Franciszek music player → 현재 캐릭터에 연결**을 누릅니다. 다른 카드와 그룹 채팅에서는 재생을 중단합니다.

기존 1.0의 카드 연결·테마·음량은 처음에 가져옵니다. 이전 선곡 프롬프트와 곡 목록은 사용하지 않습니다. 자동 선곡은 처음에는 꺼져 있습니다.

## 플레이어
- 목록 화살표는 작은 반투명 ▼/▲입니다. 모바일 아이콘은 호버로 배경이 변하지 않습니다. 활성 상태의 AI 배경은 유지합니다. 긴 제목 이동 속도는 2.0.9의 두 배입니다.
- 모바일(화면 너비 768px 이하 또는 주 포인터가 터치)에서는 플레이어 음량을 100%로 고정하고 음량 슬라이더를 숨깁니다. 기기의 물리 볼륨으로 조절하세요. 데스크톱으로 돌아오면 기존 데스크톱 음량을 복원합니다.
- 아이콘과 AI 버튼은 산세리프, 곡명·본문·설정 텍스트는 기존 명조체를 사용합니다.
- 긴 제목은 줄바꿈 없이 천천히 왕복 스크롤합니다. 짧은 제목은 고정됩니다. 화면 너비와 글꼴 로딩에 맞춰 자동 계산하며, 기기의 동작 줄이기 설정에서는 자동 이동 대신 가로 스크롤을 제공합니다.
- 기본 곡 및 초기 순서: 왈츠 → 프렐류드 → 발라드 → 녹턴.
- ⌂: 기본 왈츠로 돌아가기. 설정에서 왈츠를 제외하면 비활성화됩니다.
- → / ⤨: 순차 / 랜덤. 랜덤은 다른 활성 곡 중에서 고릅니다.
- ↻ / ↻₁: 전체 반복 / 한 곡 반복. 한 곡 반복 중에도 이전·다음 버튼은 다른 곡으로 이동합니다.
- ▼ / ▲: 곡 목록 펼치기 / 접기. 각 항목의 ⠿을 드래그해 순서를 바꿉니다. 터치 또는 키보드 위·아래 방향키도 지원합니다.
- 진행바로 위치 이동, 양끝의 진행시간·전체시간 확인, 작은 음량 슬라이더 사용.
- −: 전체 → 이전/재생/다음 → 재생만. ＋: 재생만 → 이전/재생/다음 → 전체. 두 버튼 모두 한 단계씩 이동하고 끝 단계에서는 해당 버튼이 비활성화됩니다. 축소 상태에도 이동 손잡이와 크기 버튼은 작게 남깁니다.
- 설정의 **플레이어 활성화**를 끄면 플레이어를 숨기고 재생·자동 선곡 요청을 중단합니다. 확장 설정의 음악 설정에서 다시 켤 수 있습니다.
- 상단 ⠿으로 플레이어 이동. 방향키로도 이동할 수 있습니다.
- 화이트·다크 테마는 설정에서 선택합니다.
- 곡 체크박스는 일반 재생에만 적용됩니다. 일반 재생에서 전부 해제하면 재생을 멈춥니다. 자동 선곡 모드에서는 체크 여부와 관계없이 네 곡 모두 후보가 됩니다.
- 브라우저가 최초 자동재생을 차단하면 ▶를 한 번 눌러 주세요.

## AI 자동 선곡
**분위기가 바뀌어 다른 곡을 선택하면 현재 곡을 즉시 중단하고 선택 곡을 처음부터 재생합니다.** 무음 선택일 때만 기존대로 현재 곡을 끝까지 재생한 뒤 쉽니다.

설정 → 선곡 프롬프트에서 전체 선곡 지시를 직접 수정할 수 있습니다. 입력 내용은 자동 저장되며 다음 선곡 요청부터 적용됩니다. **기본 선곡 프롬프트로 초기화**는 이 버전의 기본 지시로 되돌립니다. 곡별 분위기 초기화와는 별개입니다. 기본 지시 원문은 `core.mjs`의 `DEFAULT_SELECTION_PROMPT`에 있습니다. 빈칸은 기본값을 사용합니다. JSON 사용법은 몰라도 됩니다. “Prefer nocturnes at night”, “Play music only when the scene needs it”처럼 자연어로 적으면 됩니다. 응답 형식은 확장 내부의 별도 지시에서 처리합니다. 초기화는 쉬운 영어 기본 지시로 돌아갑니다. 기존의 기술적인 기본 프롬프트는 업데이트 시 자연어 영어 기본값으로 바뀌며, 직접 수정한 프롬프트는 보존됩니다.

자동 선곡 중에는 분위기가 바뀌지 않는 한 현재 곡이 끝나면 같은 곡을 반복합니다. 이 모드에서는 순차·랜덤 및 전체 반복보다 분위기 유지가 우선합니다. AI가 음악 없는 장면이 더 적절하다고 판단하면 현재 곡을 끊지 않고 끝까지 재생한 다음 대기합니다. 이후 새 채팅 출력에서 음악이 필요하다고 판단하면 선택한 곡을 재생합니다. 자동 선곡 모드에서는 직접 일시정지했더라도 이후 새 채팅 출력에 대한 AI 판단이 음악 재생을 선택하면 해당 곡을 처음부터 재생합니다. 일시정지했던 곡에는 우선권을 주지 않고 새 장면에 맞춰 다시 선곡합니다. 같은 곡이 다시 선택되어도 처음부터 재생합니다. 자동 선곡을 끄면 이 자동 재개는 발생하지 않습니다. 수동 재생·곡 선택은 음악 없는 상태를 해제합니다.
AI 버튼의 둥근 네모 배경이 있으면 켜짐, 없으면 꺼짐입니다. 호버로 배경이 바뀌지 않으며 켜기·끄기 안내 문구를 출력하지 않습니다.
설정에서 **Google AI Studio / Google Vertex AI** 중 사용할 등록 연결과 Gemini Flash 3.7 / 3.8 모델을 선택하고 자동 선곡을 켭니다. API 키는 확장에서 입력하지 않습니다. SillyTavern의 API 연결 설정에 해당 서비스의 인증 정보가 먼저 등록되어 있어야 합니다. 여러 키가 등록된 경우 해당 서비스에서 활성화된 키를 서버가 사용합니다.

Vertex AI는 SillyTavern에 저장된 Express/Full 인증 방식, 리전 및 Express 프로젝트 설정을 사용합니다. Full 방식은 등록된 서비스 계정 인증을 사용합니다. 선택한 모델의 사용 가능 여부는 계정·리전에 따라 달라질 수 있습니다. 채팅 모델이나 연결 선택을 변경하지 않고 별도 선곡 요청만 SillyTavern 서버로 보냅니다. 확장은 원문 API 키를 읽거나 저장하지 않습니다. 역방향 프록시는 사용하지 않습니다.

**자동 선곡 OFF: 확장은 AI 요청을 보내지 않습니다.** 대기 타이머와 진행 중 HTTP 요청을 취소하고 늦게 도착한 결과를 버립니다. 이미 Google에 접수된 요청의 서버 처리·과금까지 취소되는 것은 보장할 수 없습니다. 음악 재생과 수동 조작은 AI 연결 없이 작동합니다.

자동 선곡의 입력은 **현재 메시지를 포함하여 사용자와 캐릭터 메시지를 합친 최신 3개**입니다. 예를 들어 `캐릭터 → 사용자 → 캐릭터(현재)` 순서의 3개를 사용하며, 3턴(6개)이 아닙니다. 대화가 3개 미만이면 있는 메시지만 사용합니다. 시스템 메시지와 빈 메시지는 제외합니다. 각 메시지의 역할과 원문을 전달합니다.

SillyTavern에 설정된 문체·캐릭터 행동·스토리 지시, 프롬프트 프리셋, 프리필, 로어북, 전체 Chat History는 가져오지 않습니다. 선곡 전용 규칙, 내장된 네 곡과 분위기, 현재 재생 상태만 최신 메시지와 함께 보냅니다. 저장된 Google 인증 연결만 사용합니다. 기존 프롬프트 수집을 위한 내부 함수 연결도 제거했습니다.

사용자 또는 캐릭터 메시지가 표시되면 분석을 예약하며, 캐릭터 응답 생성 중에는 완료될 때까지 기다렸다가 최신 3개로 분석합니다. 같은 입력은 중복 분석하지 않습니다. 자동 선곡이 꺼져 있으면 메시지가 추가되어도 AI를 호출하지 않습니다. 재생 중 분위기와 곡이 유지되면 재시작하지 않고, 직접 일시정지한 후 새 장면에서 곡이 선택되면 처음부터 재생합니다.

곡 분위기는 설정에서 각각 수정할 수 있습니다. 초기화는 분위기만 아래 값으로 되돌립니다.

|곡|기본 분위기|연주자 표기|
|---|---|---|
|왈츠|기본 디폴트, 일상|Aleksander Wierzyński|
|프렐류드|일상, 유쾌, 화창|Étienne Moreau|
|발라드|고뇌, 극적, 비극|Piotr Nowakowski|
|녹턴|밤, 서정적, 로맨틱|Piotr Nowakowski|

오류·연결 실패 시 현재 곡을 유지하며 상태 문구로 알립니다. 계정에서 선택 모델을 사용할 수 있어야 합니다.

## GitHub로 설치 링크 만들기
이 폴더 안의 파일과 media/covers/fonts 폴더를 GitHub 저장소 최상위에 올리면 됩니다. 그 저장소 URL을 SillyTavern의 확장 설치에 붙여 넣습니다. 이 배포본에는 실제 GitHub 게시가 포함되어 있지 않습니다. 단순 음악 재생은 HTML 게시글로 설치할 수 없으며 이 확장 설치가 필요합니다.

음악·표지는 사용자가 제공한 원본이며 이 패키지의 코드 라이선스와 별개입니다. 설정과 음악가 표기는 허구의 창작 설정입니다.

자동 선곡을 끄면 일반 재생의 체크 목록이 다시 적용됩니다. 현재 곡이 일반 재생에서 제외되어 있으면 체크된 곡으로 전환하고, 체크된 곡이 없으면 멈춥니다.
